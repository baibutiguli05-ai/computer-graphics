# STICK RUN


C++ және OpenGL 3.3 арқылы жазылған 2D шексіз жүгіру ойыны (endless runner). Таяқша адам (stickman) жүгіреді, ал ойыншы кедергілерден секіріп, еңкейіп, шұңқырлардан өтуі керек. Бүкіл ойын бір `main.cpp` файлында.

## Ойын ережелері

Таяқша адам автоматты түрде алға жүгіреді. Жылдамдық уақыт өткен сайын артады (330-дан бастап, секундына +7). Мақсат: мүмкіндігінше ұзақ қашықтық жүгіру. Қашықтық метрмен есептеледі және терезе атауында көрсетіледі (`STICK RUN | 120 m | Best: 340 m`).

### Басқару

| Перне | Әрекеті |
|---|---|
| `SPACE` / `↑` / `W` | Секіру. Ауада тағы бір рет басса, екінші секіру (double jump) |
| `↓` / `S` | Жерде: сырғанау (төмен кедергінің астынан өту). Ауада: тезірек түсу |
| `SPACE` (ойын біткенде) | Қайта бастау |
| `ESC` | Ойыннан шығу |

### Кедергілер

| Түрі | Сипаттамасы | Қалай өту керек |
|---|---|---|
| Қорап (`BOX`) | Жердегі қызғылт сары блок | Үстінен секіру |
| Төбелік жолақ (`BAR`) | Жоғарыдан түсіп тұрған жолақ | Астынан сырғанап өту |
| Шұңқыр (`GAP`) | Жердегі тесік | Үстінен секіру. Түсіп кетсең, ойын бітеді |

Ойын ұзаққа созылған сайын кедергілер биік әрі кең болады, аралықтары қысқарады (қиындық деңгейі 6000 бірлік қашықтықта максимумға жетеді).

## Талаптар

- C++11 (немесе жаңарақ) компиляторы
- [GLFW 3](https://www.glfw.org/)
- [glad](https://gen.glad.sh/) (glad 2, `glad/gl.h` және `gl.c`), OpenGL 3.3 Core профилімен жасалған
- OpenGL 3.3 қолдайтын видеокарта

## Құрастыру және іске қосу

Жоба құрылымы:

```
stick-run/
├── main.cpp
├── glad/
│   └── gl.h
├── src/
│   └── gl.c        # glad генерациялаған файл
└── README.md
```

### Linux

```bash
sudo apt install libglfw3-dev
gcc -c src/gl.c -I. -o gl.o
g++ main.cpp gl.o -I. -lglfw -ldl -o stickrun
./stickrun
```

### macOS

```bash
brew install glfw
gcc -c src/gl.c -I. -o gl.o
g++ main.cpp gl.o -I. $(pkg-config --cflags --libs glfw3) -framework OpenGL -o stickrun
./stickrun
```

### Windows (MinGW)

```bash
gcc -c src/gl.c -I. -o gl.o
g++ main.cpp gl.o -I. -I<glfw>/include -L<glfw>/lib -lglfw3 -lopengl32 -lgdi32 -o stickrun.exe
```

Visual Studio қолдансаңыз: `main.cpp` және `gl.c` файлдарын жобаға қосып, GLFW include/lib жолдарын көрсетіңіз, `opengl32.lib` пен `glfw3.lib` кітапханаларын байланыстырыңыз.

## Код құрылымы

| Бөлім | Не істейді |
|---|---|
| `reset()` | Ойынды бастапқы күйге келтіреді |
| `jump()` | Секіру және қос секіру логикасы, өлген соң қайта бастау |
| `spawn()` | Кездейсоқ кедергі жасайды, қиындық деңгейіне қарай өлшемін таңдайды |
| `update(dt, down)` | Физика (гравитация), қозғалыс, кедергілерді жылжыту және жою, соқтығысуды тексеру |
| `overGap()` | Ойыншы шұңқыр үстінде ме, соны тексереді |
| `getPose()` | Қозғалыс күйіне қарай (жүгіру, секіру, сырғанау, құлау) таяқша адамның позасын береді |
| `drawStickman()` | Адамды аяқ-қол, дене, бас бөліктерінен салады |
| `drawScene()` | Жер, кедергілер және адамды салады |
| `main()` | GLFW терезесін, шейдерлерді құрады, негізгі циклды іске қосады |

### Техникалық ерекшеліктер

- **Бір шейдер, бір VAO.** Вертекс буфері жоқ: төбелер `gl_VertexID` арқылы шейдерде есептеледі. Тікбұрыш (`GL_TRIANGLE_STRIP`, 4 төбе), аяқ-қол (бұрылатын тікбұрыш) және шеңбер (`GL_TRIANGLE_FAN`, 34 төбе) бір вертекс шейдерімен салынады, түрі `uKind` uniform арқылы таңдалады.
- **Логикалық координаттар.** Ойын әлемі 800×450 өлшемінде есептеледі, шейдер оны экран координатына түрлендіреді. Терезе 960×540, өлшемі өзгермейді.
- **Кадр уақыты.** `dt` ең көбі 0.033 секундпен шектеледі, сондықтан кадр түсіп кетсе физика бұзылмайды. VSync қосулы (`glfwSwapInterval(1)`).
- **Анимация.** Жүгіру фазасы (`phase`) жылдамдыққа байланысты өседі, аяқ-қол бұрыштары синус функциясымен есептеледі.
- **Соқтығысу.** AABB (түзу төртбұрыштар) әдісі. Сырғанағанда ойыншының қорабы аласа әрі енді болады.
